# michulee.com

Portfolio site for Michelle Lee, data engineer. Built with [Astro](https://astro.build) and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

| Path | Page |
|---|---|
| `src/pages/index.astro` | Home |
| `src/pages/budget-pipeline/index.astro` | Budget Pipeline case study (also the Google OAuth app homepage) |
| `src/pages/budget-pipeline/privacy.astro` | Budget Pipeline privacy policy (linked from the Google OAuth consent screen) |
| `src/styles/global.css` | Colors, type and layout |

Older versions of the site (v1–v5, 2020–2023) were retired in Nov 2026; a git bundle of those branches is kept offline.
